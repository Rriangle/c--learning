## 🚀 如何部署到 GitHub Pages

### 方法一：使用 GitHub 網頁介面

1. **建立新的 GitHub 倉庫**
   - 登入 GitHub
   - 點擊右上角的 "+" 號，選擇 "New repository"
   - 倉庫名稱設為：`csharp-learning-guide`
   - 選擇 "Public"
   - 勾選 "Add a README file"
   - 點擊 "Create repository"

2. **上傳檔案**
   - 在倉庫頁面點擊 "uploading an existing file"
   - 將 `index.html` 檔案拖曳到上傳區域
   - 填寫 commit 訊息：`Add C# learning guide`
   - 點擊 "Commit changes"

3. **啟用 GitHub Pages**
   - 進入倉庫的 "Settings" 頁籤
   - 在左側選單找到 "Pages"
   - 在 "Source" 選擇 "Deploy from a branch"
   - 選擇 "main" 分支和 "/ (root)" 資料夾
   - 點擊 "Save"

4. **訪問網站**
   - 幾分鐘後，你的網站將可以在以下網址訪問：
   - `https://你的用戶名.github.io/csharp-learning-guide`

### 方法二：使用 Git 命令列

```bash
# 1. 複製倉庫到本地
git clone https://github.com/你的用戶名/csharp-learning-guide.git

# 2. 進入專案資料夾
cd csharp-learning-guide

# 3. 將 index.html 檔案放到這個資料夾

# 4. 添加檔案到 Git
git add .

# 5. 提交變更
git commit -m "Add C# learning guide"

# 6. 推送到 GitHub
git push origin main
```
