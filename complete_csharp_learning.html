🔤 資料型別與變數

▼

什麼是變數？

變數就像是一個「盒子」，可以存放不同類型的資料。在C#中，我們需要先告訴電腦這個盒子要放什麼類型的東西。

// 這是C#程式碼，我們來看看各種資料型別 using System; class Program { static void Main(string[] args) { // 1. 整數型別 (int) - 用來存放整數，例如：年齡、數量 int age = 25; // 宣告一個整數變數叫age，值為25 int studentCount = 30; // 學生人數 // 2. 字串型別 (string) - 用來存放文字，例如：姓名、地址 string name = "小明"; // 姓名 string address = "台北市信義區"; // 地址 // 3. 布林型別 (bool) - 用來存放真或假，例如：是否為學生、是否及格 bool isStudent = true; // 是學生 bool isPassed = false; // 不及格 // 4. 小數型別 (double) - 用來存放小數，例如：身高、體重 double height = 175.5; // 身高175.5公分 double weight = 65.8; // 體重65.8公斤 // 5. 字元型別 (char) - 用來存放單一字元，例如：性別 char gender = 'M'; // 性別：M代表男性 // 6. 使用var關鍵字 - 讓電腦自動判斷型別 var autoNumber = 42; // 電腦會自動判斷這是int型別 var autoText = "自動判斷"; // 電腦會自動判斷這是string型別 // 7. 常數 (const) - 不會改變的值，例如：圓周率 const double PI = 3.14159; // 圓周率，永遠不會改變 // 8. 顯示所有變數的值 Console.WriteLine("=== 學生資料 ==="); Console.WriteLine("姓名: " + name); Console.WriteLine("年齡: " + age + "歲"); Console.WriteLine("身高: " + height + "公分"); Console.WriteLine("體重: " + weight + "公斤"); Console.WriteLine("性別: " + gender); Console.WriteLine("是否為學生: " + isStudent); Console.WriteLine("是否及格: " + isPassed); Console.WriteLine("圓周率: " + PI); } }
📱 程式執行結果：

=== 學生資料 ===

姓名: 小明

年齡: 25歲

身高: 175.5公分

體重: 65.8公斤

性別: M

是否為學生: True

是否及格: False

圓周率: 3.14159

💡 重要提醒：
  • 變數命名規則： 變數名稱不能以數字開頭，不能有空格，建議使用有意義的名稱
  • 型別安全： C#是強型別語言，一旦宣告了型別就不能隨便改變
  • 分號結尾： 每行程式碼後面都要加分號(;)
  • 字串用雙引號： 字串要用雙引號("")包起來，字元用單引號('')
